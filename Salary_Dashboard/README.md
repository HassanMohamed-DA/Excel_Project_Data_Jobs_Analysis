#  Salary Dashboard

##  Introduction
This **Data Jobs Salary Dashboard** was created to help job seekers investigate salaries for their desired roles and ensure they are being adequately compensated.  
The dataset contains real-world, detailed information on job titles, salaries, locations, and essential skills — all presented visually and interactively in the dashboard.

## ⚙️ Dashboard Build Details

### 📊 Data Science Job Salaries - Bar Chart

- **🛠️ Excel Features:** Utilized bar chart with formatted salary values and optimized layout for readability.  
- **🎨 Design Choice:** Horizontal bar chart for clear visual comparison of median salaries.  
- **📉 Data Organization:** Job titles sorted by descending salary.  
- **💡 Insights Gained:** Senior roles and engineering positions generally command higher salaries than analyst roles.
